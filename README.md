# Node.js + MongoDB Step-by-Step Course

Welcome to the Node.js and MongoDB hands-on project course! This repository is structured sequentially to help you build a complete application from scratch, moving from basic setup to a fully functional backend.

---

## 🚀 How to Use This Repository

The entire course is divided into progressive steps. Each step is saved as a specific Git tag, from **`step1`** to **`step24`**. This allows you to jump to any point in the course or compare your code with the reference solution.

### Checking Out a Specific Step

To view the code at any particular stage of the project, use the `git checkout` command followed by the tag name:

```bash
# Example: Jump to Step 1 (Project Initialization)
git checkout step1

# Example: Jump to Step 12 (Middle of the course)
git checkout step12
```

To go back to the latest code on your main branch:

```bash
git checkout dev
```
