========== Separate codes of 'usersRoute.js' into MVC ==========

1. extract functions from the routes in 'usersRoute.js'

2. in folder 'controllers':
    create 'usersController.js'

3. move the functions from 'usersRoute.js' to 'usersController.js'

4. add 'export' in front of each function in 'usersController.js'

5. import the neccessary modules, packages in 'usersController.js'
    import bcrypt from "bcryptjs";
    import passport from "passport";
    import User from "../models/Users.js";

6. remove the unused modules, packages in 'usersRoute.js'
    - bcryptjs
    - passport
    - Users.js

7. import functions from 'usersController.js' in 'usersRoute.js'

8. check whether the function still works properly after moving and importing functions.
