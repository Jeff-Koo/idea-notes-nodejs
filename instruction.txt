========== MVC architectural pattern ==========
    M : models
    V : views
    C : controllers

Separate the codes into MVC architectural pattern 


1. extract the function from routes (except "/" "/about", "*"). 
    e.g.FROM:
        app.get("/ideas/add", 
            (req, res) => {
                res.render("ideas/add");
            }
        );

        TO:
        const getAddIdea = (req, res) => {
            res.render("ideas/add");
        }

        app.get("/ideas/add", getAddIdea);

2. check whether the function still works properly after extracting the functions.
