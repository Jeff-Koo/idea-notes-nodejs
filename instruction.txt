========== separate the routes ==========

1. create folder 'routes' under folder 'IdeaNotes'

2. inside folder 'routes': create 'ideasRoute.js'  

3. import express  in 'ideasRoute.js'

4. move the routes related to ideas  to 'ideasRoute.js'
    "/ideas/add"
    "/ideas"
    "/ideas/:id"
    "/ideas/edit/(:id)"

5. import functions from 'ideasController.js'  in 'ideasRoute.js'
    beware of the file path when import 

6. use express.Router() in 'ideasRoute.js'
    const router = express.Router();
    change all 'app' to 'router'

7. modify the routes   
    "/ideas/add"         --> "/add"
    "/ideas"             --> "/"
    "/ideas/:id"         --> "/:id"
    "/ideas/edit/(:id)"  --> "/edit/:id"

8. export default router;  // in 'ideasRoute.js'

9. in 'app.js': 
    remove the import functions from 'ideasController.js'

10. in 'app.js', add codes:
    import ideasRoute from "./routes/ideasRoute.js"
    
11. in 'app.js', add code: 
        app.use("/ideas", ideasRoute);  // before app.use("*")

12. check whether the application works properly
