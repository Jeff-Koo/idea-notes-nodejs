========== set cookie to logout user if user idle for a long time ==========

1. in 'app.js':
    set cookie in express-session 
    if user logged in but idle for 30 second, 
    then the cookie will clear and the user is logged out
    

========== create a private file to protect important information ==========
    '.env' file is a file to store secret environment variables

2. install dotenv package by the following command:
    npm i dotenv

3. in folder 'IdeaNotes' : 
    create '.env' file
        set PORT number & the URI for mongoDB

4. in 'app.js': 
    import dotenv from "dotenv";
    dotenv.config();

5. in 'app.js':
    change some lines to use the value in .env
      - mongoose
          .connect(process.env.mongoURI)
          .then...
        
      - const PORT = process.env.PORT || 3200;
