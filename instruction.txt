========== set up Login function ==========

2.  npm i passport
    npm i passport-local

3. create folder 'config' under 'IdeaNotes'

4. inside folder 'config':
    create 'passportConfig.js'

5. inside 'app.js': 
    // load passport 
    import passport from "passport";
    import passportConfig from "./config/passportConfig.js";
    passportConfig(passport);

6. write routes in 'usersRoute.js' for "/login"
    (together with the functions, we will extract the function later)
    remember to import passport in 'usersRoute.js'
    
7. check whether the code works properly
    if login successful, the page will redirect to "/ideas" 
    if login failed, the page remain at "/users/login" with empty input field
