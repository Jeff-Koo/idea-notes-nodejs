========== create Users model and set up Register function ==========

1. inside 'views' folder: create folder 'users'

2. inside 'views/users' folder: create 'login.handlebars'

3. inside 'views/users' folder: create 'register.handlebars'

4. add <a href=""> for going to register page, login page  in '_navbar.handlebars'

5. inside 'models' folder: create 'Users.js'  (import mongoose)

6. inside 'routes' folder: create 'usersRoute.js' (import express)

7. write routes in 'usersRoute.js' for "/register" 
    (together with the functions, we will extract the function later)

8. add codes in 'app.js'
    import usersRoute from "./routes/usersRoute.js"
    app.use("/users", usersRoute);  // before app.use("*")

9. check whether the register page works properly
    error message will show if there is invalid input
    if no error message, the page will redirect to Home page
