========== set logout function ==========

1. in '_navbar.handlebars': 
    add hyperlink item for logout  
    <li>
        <a class="nav-link" href="/users/logout">Logout</a>
    </li>

2. write route in 'usersRoute.js' for "/logout" 

3. check whether logout works properly by seeing the console.log message
    the user information will be shown on console after login
    the user information will be set to null after logout
