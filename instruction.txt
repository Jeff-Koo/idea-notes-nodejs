========== upload image by using multer ==========

1. npm install multer

2. write post route in 'usersRoute.js' for "/profile":
    router.post("/profile", postProfile);
    remember to import { postProfile } from "../controllers/usersController.js"

3. write the function postProfile in 'usersController.js':
    export const postProfile = (req, res) => { 
        res.redirect("/users/profile") 
    };
    // for now simply redirect to profile page after clicking the 'Upload Avatar' button

4. create folder 'uploads' in folder 'IdeaNotes'


===== inside 'usersController.js' do the following steps: ===== 

5. import necessary packages: 
    import multer from "multer"
    import * as fs from "fs";

6. make the setting of storage in multer
    - set destination   (which folder the input file put into temporarily)
    - set filename      (what name should the input file be in the backend server)
   
7. create function for uploading image with multer:
    export const uploadAvatar = multer({ 
        storage: storageSetting,
        fileFilter : (req, res) => { /* set filter: what type of file can be uploaded) */  }   
    }).single("avatarUpload");

8. in 'usersController.js':  postProfile() :
    write codes to store the data of image to mongoDB
    remove  res.redirect("/users/profile")  


===== modify post route in 'usersRoute.js' =====

9.  import uploadAvatar from "../controllers/usersController.js"
    router.post("/profile", uploadAvatar, postProfile);

10. check mongoDB to see whether the image is uploaded and saved in mongoDB
    if uploaded successfully, 
        inside collection 'users', the document of the user will have the field 'avatar' Object,
        which contains 'data' and 'contentType'
