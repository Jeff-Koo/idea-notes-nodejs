========== showing static contents (images) in NodeJS website ==========
    need to set a static folder 'public'

1. inside folder 'views':
    create folder 'public'

2. inside folder 'public':
    create folder 'img'

3. inside folder 'img':
    put some image files 
        - favicon.ico (may use https://www.favicon.cc/ to draw .ico file)
        - logo.png

4. in 'app.js': 
    add code with express.static 

5. in '_navbar.handlebars': 
    add <div><img /></div> for showing 'logo.png' 

6. in 'main.handlebars': 
    add <link rel="icon"> for showing 'favicon.ico'
    (animated 'favicon.ico' only works in Firefox)

7. check whether the image show properly (especially in Add Notes page, Edit Note page)
