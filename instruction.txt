========== set up session after login ==========

1. in 'usersRoute.js' : router.post("/login") : 
    remove "session: false" (session will be set true by default)

2. set up middleware for passport and login session 
    in 'app.js' (after the express-session middleware):
        app.use(passport.initialize());
        app.use(passport.session());

3. in 'passportConfig.js':
    add passport.serializeUser()
    add passport.deserializeUser()

4. in 'app.js' (set global variable):
    res.locals.user = req.user || null;
