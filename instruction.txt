========== format the routes of 'ideasRoute.js' and 'usersRoute.js' ==========

1. use .route() to make the SAME routes together
    e.g.:
        router.get("/add", getAddIdea);
        router.post("/add", postAddIdea);
        -->  router.route("/add").get(getAddIdea).post(postAddIdea);

    
2. check whether the functions still work properly after changing the codes. 


========== protect the routes from the unauthorized user  ==========

    only login user can access the routes start with '/ideas': 
        'Add Notes' page, 
        'Notes' page, 
        'Edit Note' page, 
        'Delete Note' page

3. create folder 'helpers' inside 'IdeaNotes'

4. inside folder 'helpers':
    create 'auth.js'


version 1 (protect the specific page) :

5. in 'ideasRoute.js':
    import ensureAuthenticated from "../helpers/auth.js";
    add "ensureAuthenticated" middleware to before "getAddIdea" and "postAddIdea"

    e.g. router.route("/add").get(ensureAuthenticated, getAddIdea).post(ensureAuthenticated, postAddIdea);

6. check by accessing localhost:3100/ideas/add,
    the page will redirect to 'Login' page if the protection works 

version 2 (protect all pages in '/ideas') :

7. now you can undo the changes in 5. 
    by removing "ensureAuthenticated" middleware from 'ideasRoute.js'

8. in 'app.js':
    import ensureAuthenticated from "./helpers/auth.js";
    add "ensureAuthenticated" middleware to "/ideas" route


9. check by accessing localhost:3100/ideas/add, 
                      localhost:3100/ideas
                      localhost:3100/ideas/edit/630c82ea9540f25d25ff2cf4
    the page will redirect to 'Login' page if the protection works
